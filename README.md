# Low Cost Vibes - Transylvania Holiday Deal Page

This project is a holiday deal landing page for a Transylvania travel package. It was developed as part of the Low Cost Vibes UI/UX Engineer Intern technical assessment.

The page brings together the main travel package information, including the itinerary, hotel, destinations, excursions and payment details.

## Technologies Used

- Next.js
- React
- JavaScript
- CSS Modules
- HTML and CSS

## Features

- Responsive layout for desktop and mobile
- Travel package overview and image gallery
- Hero section with package details and pricing
- Holiday highlights
- Expandable itinerary
- Hotel information
- Interactive destination tabs
- Excursion details
- Payment information
- Expandable fine print
- FAQ accordion
- Testimonials
- Enquiry form with submission feedback

## Running the Project

Clone the repository:

```bash
git clone https://github.com/Alokajs/lcv-transylvania-deal-page.git
```

Navigate to the project folder:

```bash
cd lcv-transylvania-deal-page
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open http://localhost:3000 in your browser to view the project.
